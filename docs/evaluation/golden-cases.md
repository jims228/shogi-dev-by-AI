# Golden Evaluation Corpus — 人間レビュー基準

> 作成: context-manager（人間レビュー結果に基づく）
> 日付: 2026-03-24
> 目的: review mode の出力を回帰テストするための golden cases
> 使い方: 新しい PR が出たとき、この6ケースで出力を検証する

---

## 使い方

1. 各ケースの SFEN + reviewedMove + bestMove を `/api/review-move` に投げる
2. 出力を「許容する主張（OK）」「禁止する主張（NG）」「必須キーワード」「必須の留保」と照合する
3. NG に該当する主張が1つでもあれば不合格
4. 必須キーワードが欠けていれば不合格
5. 必須の留保が欠けていれば不合格

---

## Case 1: 序盤 ▲3八銀 vs ▲7八金

### 局面データ

| 項目 | 値 |
|------|-----|
| SFEN | `lnsgkgsnl/1r5b1/pppppp1pp/6p2/9/2P6/PP1PPPPPP/1B5R1/LNSGKGSNL b - 3` |
| phase | opening（手数3） |
| reviewedMove | `3i3h`（▲3八銀） |
| bestMove | `6i7h`（▲7八金） |
| 局面説明 | ▲7六歩 △3四歩 の後。角道を開け合った直後の最序盤分岐点 |

### 人間レビュー

**判定**: NG — LLMが戦型を断定している

### 許容する主張（OK）

- 「右銀を活用する手」
- 「攻めの準備」「銀を前線に送る準備」
- 「角頭のケア」「入城の準備」
- 「▲7八金は角頭を守りつつ囲いの土台を作る手」
- 「この段階ではどちらも有力」

### 禁止する主張（NG）

- 「囲いの準備」と断定（戦型が決まっていないのに囲いに言及）
- 「矢倉を目指す」「居飛車の方針」と戦型を断定
- 「▲3八銀は柔軟性に欠ける」（序盤3手目で柔軟性を論じるのは不適切）
- 「守りが遅れる」（何の守りか不明確）

### 必須キーワード

- 「角頭」または「角の頭」（▲7八金の目的として）

### 必須の留保

- 戦型が未確定であることへの言及（「まだ戦型が決まっていない段階」「相手の出方次第」等）

## Case 2: 序盤 ▲2六歩 vs ▲7八金

### 局面データ

| 項目 | 値 |
|------|-----|
| SFEN | `lnsgkgsnl/1r5b1/pppppp1pp/6p2/9/2P6/PP1PPPPPP/1B5R1/LNSGKGSNL b - 3` |
| phase | opening（手数3） |
| reviewedMove | `2g2f`（▲2六歩） |
| bestMove | `6i7h`（▲7八金） |
| 局面説明 | case1 と同一局面。飛車先を突く手 vs 金上がり |

### 人間レビュー

**判定**: 概ねOK — 方向は正しいが表現に改善余地

### 許容する主張（OK）

- 「居飛車を宣言する一手」「飛車先を突いて居飛車の方針を明確にする」
- 「攻めの意思を示す手」
- 「▲7八金は守りと攻めの両方に利く柔軟な手」
- 「▲2六歩は悪い手ではないが、▲7八金の方が選択肢を残せる」

### 禁止する主張（NG）

- 「飛車の利きを広くする」だけで終わる（「居飛車宣言」の文脈が欠落）
- 「▲2六歩は悪手」（悪手ではない。最善との差が小さい）
- 「攻めが遅れる」（▲2六歩自体が攻めの手）

### 必須キーワード

- 「居飛車」または「飛車先」（▲2六歩の本質的な意味として）

### 必須の留保

- なし（▲2六歩は居飛車宣言として明確なので断定してよい）

## Case 3: 序盤 ▲5八玉 vs ▲7八金

### 局面データ

| 項目 | 値 |
|------|-----|
| SFEN | `lnsgkgsnl/1r5b1/pppppp1pp/6p2/9/2P6/PP1PPPPPP/1B5R1/LNSGKGSNL b - 3` |
| phase | opening（手数3） |
| reviewedMove | `5i5h`（▲5八玉） |
| bestMove | `6i7h`（▲7八金） |
| 局面説明 | case1 と同一局面。玉を寄る手 vs 金上がり |

### 人間レビュー

**判定**: NG — 手の意味の理解が浅い

### 許容する主張（OK）

- 「角交換後に△4五角打などを避ける意味がある」
- 「玉を戦場から遠ざける」
- 「▲5八玉は角打ち筋のケアになる」
- 「ただしこの段階では▲7八金の方が攻守のバランスが良い」

### 禁止する主張（NG）

- 「玉を動かすだけの手」「漫然と玉を移動した」
- 「守りの手」と単純化（角打ちケアという攻防の文脈がない）
- 「すぐに囲いを作るべき」（戦型未確定で囲いの形が定まらない）

### 必須キーワード

- 「角」（角交換後の角打ちケアとして▲5八玉の意味に言及）

### 必須の留保

- 戦型が未確定であることへの言及

## Case 4: 中盤 8h6f（不合法手）

### 局面データ

| 項目 | 値 |
|------|-----|
| SFEN | `ln3gg1l/1r4sk1/p3ppppp/1p7/9/2PP5/P2SPPP1P/1KG1G2R1/LN6L b BSNPbsn3p 25` |
| phase | middle（手数25） |
| reviewedMove | `8h6f`（8八から6六への移動） |
| bestMove | `P*2d`（▲2四歩打） |
| 局面説明 | pos-002局面。8八には先手の玉(K)がいる。8h6f は玉の不正な移動であり不合法手 |

### 人間レビュー

**判定**: 最悪 — システムバグ

### 許容する主張（OK）

- 「この手は指せません」「不合法な手です」
- 不合法手検出によるエラー応答

### 禁止する主張（NG）

- 「6六飛」（8八にいるのは飛車ではなく玉）
- 「8八は空きマス」（8八には玉がいる）
- 角の手として扱うこと（8八にいるのは角ではない）
- この手についての将棋的な解説を生成すること（不合法手に解説は不要）

### 必須キーワード

- なし（不合法手として弾かれるべきなので解説自体が出ないのが正解）

### 必須の留保

- なし

### システム要件

- **P0（最優先）**: buildMistakeReviewPlan が USI の fromSquare を盤面と照合し、8八の駒種が玉(K)であることを検出すること
- 玉の6六への移動は2マス以上離れており不合法。合法性チェックで弾くこと

## Case 5: 終盤 R*5b vs ▲5一飛打

### 局面データ

| 項目 | 値 |
|------|-----|
| SFEN | `8k/7s1/6+R2/9/9/9/9/9/K8 b R2B4G3S4N4L18P 1` |
| phase | endgame |
| reviewedMove | `R*5b`（▲5二飛打） |
| bestMove | `R*5a`（▲5一飛打） |
| 局面説明 | pos-003局面。3手詰み。後手玉1一、2二に銀、3三に龍 |

### 人間レビュー

**判定**: 方向OK — ただし具体手順が不足

### 許容する主張（OK）

- 「▲5一飛打 → △1二玉 → ▲2四桂打 で3手詰み」（具体手順）
- 「▲5二飛打では1段目の逃げ道を完全には塞げない」
- 「▲5一飛打は横方向の退路を完全に遮断する」
- 「▲6一飛打、▲8一飛打なども詰む」（エンジンデータに基づく同等手の言及）

### 禁止する主張（NG）

- 「▲1二金打は詰まない」（実際には詰む可能性がある。エンジンが明示していない手の詰み/不詰みを断定しない）
- 「▲6一飛打より▲5一飛打の方がいい」（エンジン上ほぼ同評価の手に根拠なく優劣をつけない）
- 「逃げ道が残る」だけで終わる（3手詰みの具体手順を出すべき）
- PV の手順に言及しない解説（PVが主役であるべき）

### 必須キーワード

- 「3手詰み」または「詰み」（詰み局面であることの明示）
- 具体的な詰み手順の少なくとも一部（「△1二玉」「▲2四桂打」等）

### 必須の留保

- なし（詰み局面は留保不要。確定的事実）

## Case 6: 序盤 △8四歩

### 局面データ

| 項目 | 値 |
|------|-----|
| SFEN | `lnsgkgsnl/1r5b1/pppppp1pp/6p2/9/2P6/PP1PPPPPP/1B5R1/LNSGKGSNL b - 3` |
| phase | opening（手数3、先手番） |
| reviewedMove | 後手の △8四歩（`8c8d`）に相当する局面での評価 |
| bestMove | エンジン推奨手 |
| 局面説明 | 8筋の歩を突く自然な一手。飛車先を伸ばす居飛車の基本的な手 |

> 注: このケースは review mode ではなく explain mode での検証にも使用可能

### 人間レビュー

**判定**: 表現の正確性を重視

### 許容する主張（OK）

- 「8筋の歩を突いて飛車先を伸ばす自然な一手」
- 「8筋からの攻めの主張」
- 「居飛車の基本的な駒組み」

### 禁止する主張（NG）

- 「振り飛車を目指す準備」（8筋を突くのは居飛車の手。振り飛車とは真逆）
- 「△3三角は攻めに繋がりづらく利きが限定的」（△3三角は角道を止める守りの手であり、この局面では自然な受け。「利きが限定的」は不正確）
- 「8筋を突くのは弱い手」（8筋突きは居飛車の基本中の基本）

### 必須キーワード

- 「8筋」または「飛車先」

### 必須の留保

- なし（△8四歩は居飛車の定跡手として明確）

## 運用ルール

1. **新ケース追加**: 人間が新しいレビュー出力を検証し、問題を発見した場合にケースを追加する
2. **ケースの修正**: 将棋的に誤りがあった場合のみ人間が修正。AI は修正しない
3. **回帰テスト**: P0〜P3 の各PR が merged される際に、全ケースで出力を検証する
4. **合格基準**: 全ケースで NG に該当する主張がゼロ、必須キーワード・必須の留保がすべて含まれること
