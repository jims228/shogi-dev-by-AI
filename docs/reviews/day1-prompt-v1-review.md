> 将棋の事実として正しいか。エンジンデータとの突合で判定する。

### 採点基準（explanation-quality.md §7.1より）

| スコア | 基準 |
|--------|------|
| 5 | 将棋の事実として完全に正しい。エンジン評価との矛盾もない |
| 4 | 概ね正しい。細かいニュアンスの違いはあるが、事実の誤りはない |
| 3 | 大筋は正しいが、一部に不正確な記述がある（利きの見落とし等） |
| 2 | 主要な主張に事実の誤りがある |
