## 1. プロダクト名の候補

### 選定基準

- 初心者が親しみやすく、怖くない名前
- 「振り返り」「なぜ」「コーチ」のニュアンスが伝わる
- 検索性（将棋 × AI で見つけやすい）
- ドメイン取得可能性を考慮（.com / .app / .jp）

### 候補一覧

| # | 名前 | コンセプト | ドメイン候補 | 備考 |
|---|------|-----------|-------------|------|
| 1 | **ふりかえり将棋** | 「振り返り」を直球で。初心者に最も伝わりやすい | furikaeri-shogi.com | 日本語で親しみやすい。行為そのものが名前 |
| 2 | **なぜ将棋** | 「なぜ負けた？」の「なぜ」を核に | naze-shogi.com | 短くてキャッチー。疑問形が好奇心を刺激 |
| 3 | **将棋のなぜ** | 上記の語順違い。より日本語的 | shogi-no-naze.com | 「将棋の〇〇」は棋書タイトルの定番形式 |
| 4 | **テフリ** | 「手（te）」+「振り返り（furi）」の造語 | tefuri.app | 短く、モダン。造語のためSEO独占可能 |
| 5 | **棋コーチ** | 「棋」+「コーチ」。AI棋譜コーチのイメージ | ki-coach.com | 「コーチ」が初心者に安心感を与える |
| 6 | **NazeAI** | 英語圏にも通じる。「なぜ」+ AI | nazeai.com | グローバル展開を見据えるなら。ただしMVPは国内向け |
| 7 | **将棋かいせつくん** | ゆるいキャラクター感。親しみやすさ最大 | kaisetsukun.com | 初心者フレンドリーだがやや子供向けの印象 |
| 8 | **イッテ** | 「一手（itte）」+「良い手（ii te）」の掛け言葉 | itte.app | 短い。「その一手、なぜ？」と組み合わせられる |

### 推薦: テフリ（第1候補）/ なぜ将棋（第2候補）

**テフリを推す理由**:
- 造語のためGoogle検索・SNSで固有名詞として認識されやすい
- 4文字で覚えやすく、口コミで広がりやすい
- 「手を振り返る」という行為がそのまま名前になっている
- .app ドメインはテック・ツール系に合う
- ひらがな/カタカナどちらでも表記可能（テフリ / てふり）

**なぜ将棋を推す理由**:
- プロダクトの核（「なぜ？」に答える）が名前に直結
- 将棋初心者が「なぜ 将棋」で検索した時にヒットする
- 説明不要で機能が想像できる

### 候補一覧

| # | コピー | 狙い | 文字数 |

| 1 | **「なぜ負けた？」に、AIが3分で答えます。** | 核心体験を直球で。時間の短さも訴求 | 20文字 |
| 2 | **負けた理由が分かると、次の一手が変わる。** | Before→Afterの変化を提示。上達実感 | 19文字 |
| 3 | **評価値じゃない。言葉で分かる、あなたの将棋。** | 競合との差別化を明確に。パーソナル感 | 21文字 |
| 4 | **感想戦、AIとやろう。** | 将棋文化の「感想戦」をAIに置き換え。共感性 | 10文字 |
| 5 | **悪手の「なぜ」が分かる、はじめての将棋AI。** | 「はじめての」で初心者に安心感。差別化も明確 | 22文字 |

### 推薦: 1（メイン）+ 4（サブ）

- **メインコピー**: 「なぜ負けた？」に、AIが3分で答えます。
  - 利用シーン（負けた直後）・核心機能（なぜ）・手軽さ（3分）が全て入っている
  - SNSシェア時に「これ使ったら負けた理由わかった」と自然に接続する

- **サブコピー**: 感想戦、AIとやろう。
  - メインコピーより短く、SNSのプロフィールやOGP画像に使いやすい
  - 将棋を知っている人には「感想戦」が響く。知らない人にも「AIと」で新しさが伝わる

## 3. ターゲットユーザーのペルソナ

### ペルソナ1: タケシ（27歳・社会人・将棋ウォーズ4級）

| 項目 | 内容 |
|------|------|
| 名前 | 田中タケシ |
| 年齢 | 27歳 |
| 職業 | ITエンジニア（Web系） |
| 棋力 | 将棋ウォーズ4級（10分切れ負け） |
| 将棋歴 | 1年半。藤井聡太の活躍がきっかけで始めた |
| 利用デバイス | iPhone（メイン）、MacBook（サブ） |
| 将棋の頻度 | 平日夜に2〜3局、週末に5〜6局 |

**利用シーン**:
- 通勤電車で将棋ウォーズを指す。負けると「なんで負けたんだろう」とモヤモヤする
- 帰宅後にぴよ将棋で解析するが、評価値グラフの「ガクッと下がった地点」を見ても理由が分からない
- 「この局面、なんで▲6五桂がダメなの？ AIは▲7七桂って言ってるけど、違いが分からない」

**既存ツールへの不満**:
- 棋神解析: 課金が積み重なる。しかも「ここが悪手」と指摘されるだけで理由がない
- ぴよ将棋: 無料で解析できるのはありがたいが、読み筋を見ても3手先が理解できない
- 棋書: 居飛車の本を買ったが、途中から変化が多すぎて挫折

**このプロダクトで変わること**:
- 負けた理由が「言葉」で分かる。「▲6五桂は相手の△4四角で王手飛車の筋がある。▲7七桂なら王手の筋を消しつつ攻めの足がかりになる」
- 「次にこの形になったら、桂を跳ねる前に相手の角のラインを確認する」→ 次の対局で意識すべき1点が明確になる
- 3分で振り返りが完了するから、通勤中にもう1局指す余裕ができる

### ペルソナ2: ユキ（34歳・主婦・将棋ウォーズ5級）

| 項目 | 内容 |
|------|------|
| 名前 | 佐藤ユキ |
| 年齢 | 34歳 |
| 職業 | 主婦（パートタイム勤務） |
| 棋力 | 将棋ウォーズ5級（3分切れ負け中心） |
| 将棋歴 | 8ヶ月。子供が将棋教室に通い始め、一緒にやるようになった |
| 利用デバイス | Android スマホ（Pixel） |
| 将棋の頻度 | 子供が寝た後に1〜2局 |

**利用シーン**:
- 子供の将棋教室の先生に「お母さんも指してみたら？」と言われて始めた
- 将棋ウォーズで3分切れ負けを中心に指すが、5級から上がれない
- 「なんかいつも同じ感じで負ける気がする。でもどこが悪いか分からない」
- 棋書を買ってみたが、「▲7六歩 △3四歩 ▲2六歩...」の符号の羅列で10ページで断念

**既存ツールへの不満**:
- ぴよ将棋: 解析結果を見ても「+300」「-500」の数字の意味が直感的に分からない
- 棋書: 符号が読めない。図面があっても次のページに進むと局面が分からなくなる
- YouTube: 解説動画は面白いが、自分の対局には当てはまらない。プロの対局と自分の対局は別世界

**このプロダクトで変わること**:
- 「あなたはこの局面で玉を囲わずに攻めに行きましたが、相手の飛車が直通で玉を狙える形になっています。先に▲6八玉と1手玉を移動させるだけで、相手の攻めが届かなくなります」→ 符号なしでも理解できる言葉で説明
- 「次にこの形になったら、攻める前に『自分の玉は安全か？』を1回確認してみてください」→ 意識すべき習慣が身につく
- 子供と一緒に見て「お母さんのここがダメだったんだって！」と盛り上がれる → 家族の将棋体験が豊かになる

## 4. ユーザー獲得の初期チャネル候補

### チャネル1: 将棋ウォーズ対局後のSNSシェア導線

**なぜここか**: 将棋ウォーズのユーザーは対局結果をX（旧Twitter）にシェアする文化がある。「#将棋ウォーズ」ハッシュタグで毎日数千件の投稿がある。

**施策**:
1. **「この対局を振り返る」シェアボタン**をアプリ内に設置
   - 解説結果ページに「この振り返りをシェアする」ボタン
   - シェア文面: 「なぜ負けたか、AIに聞いてみた。→ [URL] #将棋ウォーズ #テフリ」
2. **「対局後3分チャレンジ」キャンペーン**
   - 「対局後3分で振り返ってみよう」と促すハッシュタグ企画
   - 参加者の振り返り投稿をリポストして認知拡大
3. **将棋ウォーズの棋譜URLをそのまま貼れるUX**（将来的に）
   - 現MVP: SFEN/KIFテキスト入力
   - 将来: URLを貼るだけで棋譜を読み込み → シェアの敷居が劇的に下がる

**最初の100人への到達方法**:
- 開発者自身が将棋ウォーズで対局 → 振り返り結果をXに投稿 → 「これ作ってます」
- 将棋系インフルエンサー（特に初心者向けコンテンツの人）に直接DM
- 目標: 公開1週間で50人利用、2週間で100人

---

### チャネル2: Reddit / 5ch / はてブの将棋コミュニティ

**なぜここか**: 将棋初心者が「上達法」「おすすめツール」を検索して辿り着く場所。特にはてなブックマークは技術系の新サービスが話題になりやすい。

**施策**:
1. **5ch将棋板の「初心者質問スレ」で自然に紹介**
   - 「こういうツール作ったんだけど使ってみてほしい」の開発者投稿
   - 注意: 宣伝色が強すぎると逆効果。実際の解説結果のスクリーンショットを添えて価値を示す
2. **はてなブログで開発記事を書く**
   - 「将棋AIに『なぜ悪手か』を説明させるために工夫したこと」的な技術記事
   - はてブ経由で技術者層 → 将棋好きのエンジニアに到達
3. **Reddit r/shogi での英語圏リーチ**
   - 将棋の国際的な関心は増加中。英語UIが将来対応できれば海外ユーザーも視野に
   - まずは日本語UIのまま「Here's a tool that explains WHY your move was bad in Japanese shogi」で投稿

**最初の100人への到達方法**:
- はてブのホッテントリ入りを狙う（技術記事 + 実際の解説サンプル）
- 5chの初心者スレで10人程度のフィードバックを得る
- 目標: 記事公開から3日以内に300PV → 50人利用

---

### チャネル3: 将棋系YouTuber / 配信者とのコラボ

**なぜここか**: 将棋初心者の多くがYouTubeで将棋を学んでいる。特に「初心者向け」チャンネルのファン層は、まさに本プロダクトのターゲット。

**施策**:
1. **初心者向け将棋YouTuberに無料で使ってもらう**
   - 候補: 将棋初心者向け解説チャンネル（登録者1万〜5万人規模）
   - 「視聴者さんの棋譜を振り返る企画」に使ってもらう
   - 条件: 無料。見返りは概要欄にリンクを貼ってもらうだけ
2. **「視聴者の棋譜をAIが解説」企画の提案**
   - YouTuberが視聴者の棋譜を募集 → テフリで解説 → 動画で紹介
   - 視聴者参加型なので盛り上がりやすい
3. **将棋ウォーズ配信者とのリアルタイムコラボ**
   - Twitch/YouTube Liveで将棋ウォーズ配信中に、対局後すぐテフリで振り返り
   - 「配信の合間の3分振り返り」がコンテンツになる

**最初の100人への到達方法**:
- 1人のYouTuber（登録者1万人以上）に1本の紹介動画を作ってもらう
- 動画公開から1週間で100〜300人の利用を見込む
- 目標: MVP公開2週間以内にコラボ実現

## 5. MVP公開時のランディングページ設計

### 5.1 ファーストビュー（Above the Fold）

```
┌─────────────────────────────────────────┐
│                                         │
│  [ロゴ: テフリ]                          │
│                                         │
│  「なぜ負けた？」に、                     │
│   AIが3分で答えます。                     │
│                                         │
│  あなたの対局の悪手を、言葉で説明。        │
│  次の対局で何を見るかが分かります。        │
│                                         │
│  ┌─────────────────────────────┐        │
│  │ 棋譜を貼って振り返る（無料） │        │
│  └─────────────────────────────┘        │
│                                         │
│  [解説結果のスクリーンショット]            │
│  ↑ 実際の解説画面を見せる                 │
│                                         │
└─────────────────────────────────────────┘
```

**構成要素**:
| 要素 | 内容 | 理由 |
|------|------|------|
| ロゴ | テフリ（仮）+ アイコン | ブランド認知の起点 |
| メインコピー | 「なぜ負けた？」に、AIが3分で答えます。 | 核心体験を1文で伝える |
| サブコピー | あなたの対局の悪手を、言葉で説明。次の対局で何を見るかが分かります。 | メインコピーの補足。B+Cの体験を明示 |
| CTA | 「棋譜を貼って振り返る（無料）」 | 行動が具体的。無料であることを明示 |
| ビジュアル | 実際の解説結果のスクリーンショット | 「どんな体験が得られるか」を一目で理解 |

### 5.2 セカンドセクション: Before → After

```
┌─────────────────────────────────────────┐
│                                         │
│  今まで:                                 │
│  「評価値が-500に下がった。              │
│   でも、なぜ？」                         │
│                                         │
│         ↓                               │
│                                         │
│  テフリなら:                             │
│  「▲6五桂は相手の△4四角で             │
│   王手飛車の筋があります。               │
│   次にこの形が出たら、桂を跳ねる前に     │
│   相手の角のラインを確認しましょう。」     │
│                                         │
└─────────────────────────────────────────┘
```

**狙い**: 既存ツール（評価値のみ）との差を具体例で見せる。初心者が「あ、これ私のことだ」と思える表現にする。

### 5.3 サードセクション: 3ステップ

```
┌─────────────────────────────────────────┐
│                                         │
│  使い方は3ステップ                        │
│                                         │
│  1. 棋譜を貼る                           │
│     将棋ウォーズやぴよ将棋の              │
│     棋譜をコピー&ペースト                 │
│                                         │
│  2. AIが解説                             │
│     悪手の理由を言葉で説明               │
│     「なぜ？」と追加質問もOK             │
│                                         │
│  3. 次の一手が変わる                      │
│     次の対局で意識すべき                  │
│     ポイントが1つ分かる                  │
│                                         │
└─────────────────────────────────────────┘
```

### 5.4 信頼性セクション

**初心者に安心感を与える要素**:

| 要素 | 内容 | 理由 |
|------|------|------|
| 解説サンプル | 実際の3つの局面の解説を掲載 | 「こういう答えが返ってくる」が事前に分かる |
| 技術の透明性 | 「将棋エンジンの解析データ + AIの言語化」と明示 | AIが適当に言っているのではなく根拠があることを示す |
| 限界の開示 | 「AIの解説は参考情報です。プロ棋士の指導を代替するものではありません」 | 正直さが信頼につながる。初心者は過信しがち |
| 無料・登録不要 | 「アカウント作成なしで今すぐ使えます」 | 個人情報を求めないことで敷居を下げる |
| 開発者の存在 | 「将棋ウォーズ◯級の開発者が作っています」 | 顔が見える安心感。同じ初心者目線で作っていることが伝わる |

### 5.5 CTA（行動喚起）

**プライマリCTA**: 「棋譜を貼って振り返る（無料）」
- ページ内に3回表示（ファーストビュー、3ステップの下、ページ末尾）
- ボタンの色: プロダクトのアクセントカラー（視認性の高い色）
- 遷移先: メインの解説ページ（棋譜入力画面）

**セカンダリCTA**: 「サンプル解説を見る」
- 棋譜を持っていない人向け。プリセット棋譜で解説を体験できる
- 体験後に「自分の棋譜でも試す」への導線

| 項目 | 内容 |
|------|------|
| og:title | テフリ - 「なぜ負けた？」に、AIが3分で答えます |
| og:description | あなたの対局の悪手を言葉で解説。次の対局で見るべきポイントが分かる将棋AI |
| og:image | 解説結果のスクリーンショット（1200x630px） |
