# ユーザーニーズ分析 — プロダクト方向性の再検証

> 作成: researcher セッション
> 調査日: 2026-03-24
> 目的: 技術的な実装に先立ち、ユーザーが本当に求めている体験を特定する

---

## 1. 将棋初心者が実際に困っていること

### 1.1 評価値は見えるが意味が分からない

**事実**（複数のブログ・記事から確認）:
- 棋神解析やぴよ将棋で評価値グラフは見られるが、「なぜ+500から-200に下がったのか」が分からない
- 「評価値が動いた場所」は分かっても、「何がまずかったか」は説明されない
- ある記事の表現:「10年間ソフトの評価値に不満。良い・悪いだけでは判断材料として不十分」

**解釈**: 初心者にとって評価値は「結果」であり「理解」ではない。数値の変動を言語で説明してくれるツールがないことが核心的な不満。

### 1.2 最善手を示されても「なぜ」が分からない

**事実**:
- ぴよ将棋のヒント機能はAIの推奨手と読み筋を表示するが、なぜその手が良いかは説明しない
- 棋神解析の「一手解析」は最善手+評価値+手順を表示するが、手順の意味は説明しない
- lishogi.orgのフォーラムでも「evaluation doesn't tell me why」という声がある

**解釈**: 「What（何が最善手か）」は既存ツールで解決済み。「Why（なぜそれが最善手か）」が未解決。

### 1.3 対局後の振り返りのやり方が分からない

**事実**:
- 将棋の上達法として「感想戦」（対局後の振り返り）が推奨されるが、初心者は何を見ればいいか分からない
- あるブログの推奨:「3分でいいから見直す。良い手を知ると自信がつき、悪い手を知ると改善のヒントになる」
- 推奨学習比率: 実戦60%、詰将棋10%、インプット30%

**解釈**: 初心者に必要なのは「振り返りの方法」を教えてくれるガイド。本プロジェクトは「3分の振り返り」を支援するツールになれる。

### 1.4 棋書は後半で急に難しくなる

**事実**:
- 将棋連盟の入門書ガイドに記載:「前半は分かりやすいが、後半に進むにつれて難易度が急激に上がる本がある」
- 「符号を使わない入門書」が初心者に人気 — 棋譜の座標表記自体がハードル
- 「読んだけど身につかない」は、読むだけで指さないことが原因（知識→実践のギャップ）

**解釈**: 棋書は体系的だが個別対応がない。「あなたのこの局面」に答えてくれる棋書は存在しない。ここが対話型AIの価値。

### 1.5 「一手のミスで逆転される」が理解できない

**事実**:
- 複数のブログ:「どんなに優勢でも、たった一手のミスで逆転される」
- ウォーズ5級→4級の壁は「終盤の一手の重みを理解すること」
- 3級→2級は「攻めの強さ」が必要

**解釈**: 初心者は「なぜこの一手がそんなに致命的か」を理解したい。これは本プロジェクトの「手の理由説明」機能が直接応える質問。

## 2. 既存サービスで「足りない」と言われていること

### 2.1 将棋ウォーズ 棋神解析

| 機能 | できること | 足りないこと |
|------|-----------|------------|
| グラフ | 評価値の推移を可視化 | なぜ動いたかの説明なし |
| 一手解析 | 最善手+評価値+手順 | 手順の意味の説明なし |
| 精密解析 | 悪手を点滅で表示 | なぜ悪手かの説明なし |

**ユーザーの声（推察）**: 「悪手だと分かったが、なぜ悪手か分からない。次に同じ局面で何を指せばいいか分からない。」

### 2.2 ぴよ将棋

| 機能 | できること | 足りないこと |
|------|-----------|------------|
| 棋譜解析 | 手とAI推奨手を比較 | 比較の意味の説明なし |
| ヒント | AIの推奨手+読み筋を表示 | 読み筋の意味の説明なし |
| 駒の動きガイド | 駒の移動可能マスを表示 | 戦略的な意味の説明なし |

**事実**: ぴよ将棋は「スマホで棋譜検討できるかなり珍しいアプリ」として評価されている。ただし解説は数値ベースで自然言語による説明はない。

### 2.3 棋書の限界

| 問題 | 具体例 |
|------|--------|
| 難易度の急上昇 | 前半は入門、後半は有段者向けに急変 |
| 個別対応の欠如 | 「あなたの局面」には答えてくれない |
| 座標表記のハードル | 「▲7六歩」の意味が初心者に直感的でない |
| 読むだけでは身につかない | 知識→実践のギャップ |

### 2.4 共通する「足りなさ」

**すべての既存ツールに共通して足りないもの**: 「Why」の自然言語による説明。

既存ツールは「What（何が最善手か、どこが悪手か）」には答えるが、「Why（なぜそうなのか）」には答えない。これは本プロジェクトが解決すべき核心的なギャップ。

## 3. チェス側で初心者学習に効いている体験

### 3.1 Lichess「Learn from your mistakes」

**仕組み**:
1. 対局後にエンジン解析をリクエスト
2. 「Learn from your mistakes」ボタンを押す
3. 悪手の局面に自動的に飛ぶ
4. 「この局面でもっと良い手を見つけてください」と出題される
5. 正解すると次の悪手に進む。間違えたらリトライ可能
6. 相手のミスからも学べる（盤面反転）

**なぜ初心者に効くか**:
- **能動的**: 読むだけでなく「自分で考えて指す」体験
- **文脈付き**: 自分の対局の実際の局面が素材
- **失敗OK**: 間違えてもリトライできる安心感
- **中断OK**: 途中で離れても続きから再開可能
- **パターン認識**: 同じような悪手を繰り返し練習することで定着

### 3.2 Chess.com Game Review

**仕組み**:
- 対局後に自動で全手を解析
- 各手を Brilliant / Great / Best / Good / Inaccuracy / Mistake / Blunder に分類
- 精度スコアを算出（全体の出来を数値化）

**なぜ初心者に効くか**:
- **シンプルな分類**: 6段階の色分けで直感的に良し悪しが分かる
- **達成感**: 精度スコアが上がると上達を実感できる
- **ゲーミフィケーション**: 「前回よりBlunderが減った」がモチベーションになる

### 3.3 DecodeChess

**ユーザーの評価**:
- **良い点**: 「人間の言葉で説明してくれるのが良い」「コーチがいない人の代わりになる」
- **悪い点**: 「技術的なバグが多い」「ローディングが遅い」「無料枠が少ない」
- **対象**: ELO 2000以下。1600程度のユーザーには「まだ有用」との声

**学び**: コンセプトは正しい（自然言語で「なぜ」を説明）が、実行品質（安定性、速度）が課題。

### 3.4 Dr. Wolf（チェスAIコーチ）

**特徴**:
- リアルタイムで対局中にフィードバック
- ユーザーの**ミスのパターン**を記憶し、繰り返し出現する弱点を指摘
- 「ゆっくりだが確実に上達」がコンセプト

**学び**: パーソナライズされたパターン検出は強力。「あなたは角の使い方で繰り返しミスしています」のようなフィードバックは初心者に刺さる。

### 3.5 チェス学習で効いている要素の共通点

| 要素 | 具体例 | 効果 |
|------|--------|------|
| **自分の対局が素材** | Learn from mistakes | 「自分ごと」として集中できる |
| **能動的に考える** | 正解を自分で指す | 読むだけより定着率が高い |
| **即時フィードバック** | 正誤が即座に分かる | 試行錯誤が速くなる |
| **パターン検出** | Dr. Wolf の弱点追跡 | 根本的な改善につながる |
| **シンプルな分類** | Game Review の色分け | 情報過多を防ぐ |

## 4. 「将棋を学ぶ」と「将棋の解説を読む」の違い

### 4.1 学習プロダクトで成功しているものの共通点

**事実**（ブログ・記事から）:
- 上達には「実戦6割、詰将棋1割、インプット3割」が推奨比率
- 「知識を学んでも、自分で指さないと身につかない」が定説
- 棋譜並べの効果は「約100局並べてから実感できる」→ 短期では効果を感じにくい

**成功パターン**:
1. **学び→実践→振り返り** のサイクルが回ること
2. 振り返りが**短時間**でできること（3分推奨）
3. **何を見るか**が明確であること（漫然と棋譜を見ても学べない）

### 4.2 「読んだけど身につかなかった」の原因

| 原因 | 具体例 |
|------|--------|
| **受動的すぎる** | 解説を読むだけで自分で考えていない |
| **自分の局面ではない** | プロの対局の解説は自分の棋力では再現できない |
| **1つに絞れない** | 複数の概念を同時に学ぼうとして混乱 |
| **次のアクションが不明** | 「なるほど」で終わり、次の対局で何を意識すべきか分からない |

### 4.3 本プロジェクトへの示唆

**解説を読ませるだけでは学習にならない。** 解説の後に「じゃあ次にこの局面が出たら何を見る？」まで踏み込むことで、学習プロダクトになれる。

## 5. 本プロジェクトが本当に提供すべき体験

### 5.1 各候補の評価

| 候補 | 内容 | 初心者への価値 | 技術的難易度 | 既存ツールのカバー |
|------|------|-------------|------------|-----------------|
| **A** | 「この手が良い理由」の解説 | 高 | 低（現MVP） | 棋神解析=数値のみ。言語化なし |
| **B** | 「自分の悪手がなぜ悪いか」の説明 | **最高** | 中 | **完全に未カバー** |
| **C** | 「次に同じ場面で何を見るか」のガイド | **最高** | 中 | **完全に未カバー** |
| **D** | 用語を盤面付きで引ける辞書 | 中 | 高 | 棋書・Web辞書で代替可能 |
| **E** | 「もう一度解いてみよう」のドリル | 高 | 高 | Lichess型。将棋にはない |
| **F** | 棋力帯の悪手パターン集 | 高 | 中 | 水匠チームの研究に近い |

### 5.2 調査に基づく優先順位

**事実ベースの根拠**:
1. すべての既存ツールが「What（何が最善/悪手か）」に答えているが「Why」に答えていない → **B（なぜ悪いか）が最も価値が高い**
2. 「読んだけど身につかない」の原因は次のアクションが不明 → **C（次に何を見るか）が学習効果を高める**
3. Lichess の「Learn from mistakes」が最も評価されている → 自分の対局の悪手を素材にする体験が刺さる
4. Dr. Wolf のパターン検出が支持されている → **F（悪手パターン）は長期的に価値が高い**

### 5.3 提案: B + C の組み合わせが最優先

**提案する核心体験**:

> **「あなたのこの手はなぜ悪かったか（B）を説明し、次に同じ局面が出たら何を見るか（C）を1つだけ伝える」**

この体験が提供できれば:
- 既存ツール（棋神解析、ぴよ将棋）にはない価値を提供
- 初心者の最大の不満（「なぜ負けたか分からない」）に直接応答
- 学習サイクル（対局→振り返り→次の対局で意識する点）が回る
- 3分の振り返りで完結する（長い解説は不要）

### 5.4 MVP vs 将来の体験マップ

```
MVP（現在）:
  A. 「この手が良い理由」の解説        ← 実装済み
  B. 「自分の悪手がなぜ悪いか」の説明   ← プロンプト改善で対応可能

Phase 2:
  C. 「次に何を見るか」のガイド         ← プロンプトに1文追加
  F. 「よくある悪手パターン」の提示      ← knowledge-cards の活用

Phase 3:
  E. 「もう一度解いてみよう」ドリル      ← UI実装が必要
  D. 用語の盤面付き辞書               ← 知識DB + 辞書UI
```

## 6. 結論: プロダクト方向性の再確認

### 6.1 核心メッセージの更新案

現在:
> 「将棋の局面・棋譜・変化を、初心者〜中級者にも分かる形で説明するAI」

調査結果を踏まえた更新案:
> **「あなたの対局の『なぜ？』に答え、次の対局で何を見るかを教えるAI」**

この変更の根拠:
- 「説明する」は受動的。「答える」は対話的 → 対話型Q&Aの差別化を強調
- 「あなたの対局」→ 一般論ではなくユーザーの棋譜に特化
- 「次の対局で何を見るか」→ 解説で終わらず、次のアクションまで提示

### 6.2 検証すべき仮説

| # | 仮説 | 検証方法 |
|---|------|---------|
| H1 | 「なぜ悪手か」の説明が最もユーザーに刺さる | MVP公開後にフィードバック収集 |
| H2 | 「次に何を見るか」の1文がユーザーの上達実感につながる | 再訪率で計測 |
| H3 | 3分以内の振り返りが最適な体験長さ | セッション時間で計測 |
| H4 | 対話型Q&Aが1ショット解説より満足度が高い | フィードバック比較 |
