# 競合・先行研究の調査

> 作成: researcher セッション
> 調査日: 2026-03-23
> 目的: 将棋解説AIの競合サービス・先行研究を整理し、本プロジェクトの差別化ポイントを明確にする

---

## 1. 国内の将棋AI解説サービス

### 1.1 将棋ウォーズ「棋神解析」

| 項目 | 内容 |
|------|------|
| 運営 | HEROZ株式会社 |
| URL | https://shogiwars.heroz.jp/ |
| 解説アプローチ | **評価値・グラフ型**（自然言語解説なし） |
| 対象レベル | 全レベル |
| 主な機能 | 評価値グラフ、一手解析（最善手+評価値）、精密解析（悪手を点滅表示） |
| 料金 | 棋神解析券（有料、1回1〜2枚消費） |

**特徴**: 数値と可視化に特化。「注目の一手」で悪手を特定する機能はあるが、「なぜ悪手なのか」を自然言語で説明する機能はない。評価値の上下は見えるが、初心者には「なぜ動いたか」が分からない。

**本プロジェクトとの差**: 棋神解析が「何が起きたか（数値）」を示すのに対し、本プロジェクトは「なぜ起きたか（言語）」を示す。補完関係にある。

---

### 1.2 銀星将棋10（シルバースタージャパン）

| 項目 | 内容 |
|------|------|
| 運営 | シルバースタージャパン |
| URL | https://www.silverstar.co.jp/ |
| 解説アプローチ | **ハイブリッド型**（将棋エンジン解析 + 生成AIによる言語化） |
| 対象レベル | 初心者〜上級者 |
| 発売予定 | **2026年4月3日**（PC向け） |
| 主な機能 | 任意タイミングで呼び出せる局面解説。戦法判定、形勢評価、良手/悪手の解説を自然な日本語で提示 |

**特徴**: 将棋エンジンの解析結果を生成AIで言語化するアプローチ。TGS2025でデモ展示済み。パッケージソフトとして販売予定。

**事実**: 本プロジェクトと最も近い直接競合。発売日が2026年4月3日であり、本プロジェクトのMVP期間と時期が重なる。
**解釈**: 商用製品として開発されており品質は高いと推測されるが、パッケージソフトのためWebアクセスの手軽さがない。また対話型Q&A機能の有無は不明。
**本プロジェクトとの差**: 本プロジェクトはWeb対話型（追加質問可能）。銀星将棋10は1ショット解説の可能性が高い。

### 1.3 水匠チーム「AI自動解説文生成システム」

| 項目 | 内容 |
|------|------|
| 開発 | 水匠チーム（たややん氏ほか） |
| URL | https://x.com/tayayan_ts |
| 解説アプローチ | **ハイブリッド型**（知識DB × LLM × 級位者AI） |
| 対象レベル | 初心者 |
| 発表 | 第35回世界コンピュータ将棋選手権（2025年5月） |
| 状態 | 研究/デモ段階（一般公開サービスではない） |

**特徴**: 知識DBとLLMを組み合わせ、さらに「級位者AI」を導入して初心者が陥りがちな悪手を特定。解説文を自動生成する。日経の取材記事では「ブラックボックスだったAIの意思決定を自然言語で説明」と評価。

**参考にすべき点**: 「級位者AI」の概念。初心者がどこで間違えるかを予測して、そこを重点的に解説するアプローチは本プロジェクトの解説品質向上に直接参考になる。

### 1.4 GMOインターネットグループ「LLMを用いた棋譜解説」

| 項目 | 内容 |
|------|------|
| 開発 | GMOインターネットグループ 研究開発本部 |
| URL | https://recruit.group.gmo/engineer/jisedai/blog/shogiexplanation1/ |
| 解説アプローチ | **LLM型**（やねうら王 + GPT-4o） |
| 対象レベル | 明示なし |
| 状態 | 技術ブログ + デモコード公開 |

**特徴**: やねうら王で局面を解析し、最善手・評価値・読み筋を取得してGPT-4oに解説文を生成させるパイプライン。Docker環境でデモコードをGitHubに公開。コスト面でGPT-4oは高いため軽量モデルへの移行を検討中とのこと。

**参考にすべき点**: エンジン出力→LLM入力のパイプライン設計。本プロジェクトのアーキテクチャ（SFEN→パーサー→プロンプト→Claude API）と構造が類似。

### 1.5 橋本・谷合 論文「LLMによる将棋AIの指し手の解釈」

| 項目 | 内容 |
|------|------|
| 著者 | 橋本大輝、谷合廣紀、門本淳一郎、入江英嗣（東京大学） |
| URL | https://www.interaction-ipsj.org/proceedings/2026/data/pdf/2P93.pdf |
| 発表 | IPSJ Interaction 2026（2026年2月） |
| 解説アプローチ | **ハイブリッド型**（高棋力AI × 低棋力AI × LLM） |
| 対象レベル | 初心者 |

**特徴**: 高棋力AIと低棋力AIの対局シミュレーションで初心者が陥りがちな悪手を特定。盤面の静的・動的特徴を言語化してLLMに入力し、定量情報を初心者向けの解説文に変換する手法。

**参考にすべき点**:
- 「初心者の悪手パターン」を使って解説の焦点を絞る手法
- 盤面特徴の言語化方法（静的: 駒の配置、動的: 利きの変化）
- 評価観点の設計

## 2. チェスの先行事例

### 2.1 DecodeChess

| 項目 | 内容 |
|------|------|
| URL | https://decodechess.com/ |
| 解説アプローチ | **XAI型**（Explainable AI + Stockfish NNUE） |
| 対象レベル | ELO 2000以下（初心者〜中級者） |
| 料金 | フリーミアム（無料枠 + Pro） |

**特徴**: チェスにおける「初のAIチューター」を標榜。Stockfishの解析結果を5つの観点（脅威、良手、計画、駒の機能、関連概念）に分解して自然言語で説明。LLMではなくルールベース+独自AIで言語化。7手先までの解説を生成。

**参考にすべき点**:
- 「5つの観点」での構造化は、本プロジェクトの解説構造設計の参考になる
- 「Why behind the moves」というコンセプトは本プロジェクトの核と一致
- ELO 2000以下というターゲット設定（本プロジェクトのウォーズ5級〜3級に相当する考え方）

**本プロジェクトとの差**: DecodeChessはルールベース+独自AIで解説生成。本プロジェクトはLLMによる対話型で、追加質問に答えられる柔軟性がある。

---

### 2.2 SimplifyChess

| 項目 | 内容 |
|------|------|
| URL | https://www.simplifychess.io/ |
| 解説アプローチ | **ハイブリッド型**（Stockfish + LLM） |
| 対象レベル | 全レベル（コーチ向け機能あり） |
| 状態 | ベータ |

**特徴**: Stockfishの評価をLLMで自然言語に変換。「Why is my knight on e5?」のような自然言語の質問に回答可能。コーチ向けにPDFレポート自動生成。Lichess/Chess.comからのインポート対応。

**参考にすべき点**:
- 対話型（ポジションについて質問できる）は本プロジェクトと同じアプローチ
- コーチ向けレポート生成は将来の機能拡張として参考になる
- Lichess/Chess.comインポートは、将棋ウォーズ/倶楽部24連携の将来像

---

### 2.3 ChessCoach

| 項目 | 内容 |
|------|------|
| URL | https://github.com/chrisbutner/ChessCoach |
| 解説アプローチ | **ニューラル型**（NN + 自然言語コメンタリー） |
| 対象レベル | 観戦者 |
| 状態 | オープンソース（GitHub） |

**特徴**: ニューラルネットワークベースのチェスエンジンに自然言語コメンタリー機能を統合。Lichessでボットとして稼働し、観戦者にコメンタリーを提供。「COVET sampling」という正確性を重視したサンプリング手法を採用。

**参考にすべき点**: 正確性を重視したサンプリング（COVET）の概念。LLMの出力品質を制御する手法として参考になる。

---

### 2.4 学術論文「Concept-guided Chess Commentary Generation」

| 項目 | 内容 |
|------|------|
| 発表 | NAACL 2025 |
| URL | https://aclanthology.org/2025.naacl-long.481.pdf |
| 解説アプローチ | **概念ベクトル型**（エキスパートモデルから概念を抽出 → LLMで解説生成） |

**特徴**: チェスのエキスパートモデル（Stockfish 8）から「概念ベクトル」を抽出し、LLMに優先度付きで渡して解説を生成。200,000局面のデータを使用。エキスパートの意思決定をLLMで言語化する体系的な手法。

**参考にすべき点**: 概念ベクトルの抽出は、将棋の「局面特徴量」に対応する。v2で試みた特徴抽出と同じ方向性だが、こちらはLLMへの入力方法がより体系的。

---

### 2.5 Lichess / Chess.com の既存解析機能

| 項目 | Lichess | Chess.com |
|------|---------|-----------|
| 解析エンジン | Stockfish（サーバー側） | Stockfish |
| 自然言語解説 | **なし**（提案段階） | **限定的**（ヒント機能） |
| 評価値表示 | あり | あり |
| 悪手検出 | あり（blunder/mistake/inaccuracy） | あり |

**特徴**: 両サービスとも評価値と悪手検出は強力だが、「なぜそれが悪手なのか」を自然言語で説明する機能は標準搭載されていない。Lichessではコミュニティから AI解説機能の提案が出ているが、実装されていない。

## 3. 囲碁・その他のボードゲーム

### 3.1 KataGo + KaTrain（囲碁）

| 項目 | 内容 |
|------|------|
| URL | https://github.com/sanderland/katrain |
| 解説アプローチ | **評価値型**（目数差で表示） |
| 対象レベル | 全レベル |

**特徴**: KataGoの解析結果をKaTrainのGUIで表示。勝率ではなく「目数差」で評価を表示するため、初心者にも直感的に分かりやすい。しかし自然言語による解説機能はない。

**参考にすべき点**: 「目数差」表示は、将棋の評価値を「やや有利」「大きく有利」等の言葉に変換する本プロジェクトのアプローチと同じ方向性。

### 3.2 銀星囲碁（シルバースタージャパン）

TGS2025で銀星将棋10と同様に、生成AIによる囲碁の局面解説機能をデモ展示。将棋と同じパイプライン（エンジン解析 + 生成AI言語化）を囲碁にも適用。

## 5. 本プロジェクトの差別化ポイント

| 差別化要素 | 内容 | 競合との比較 |
|-----------|------|------------|
| **対話型Q&A** | 解説に対して「なぜ？」「他の手は？」と追加質問できる | 銀星将棋10・DecodeChessは1ショット型の可能性。SimplifyChessは対話型だがチェス専用 |
| **ユーザーの過去棋譜** | ユーザー本人の対局を解説する。一般論ではなく「あなたの局面」に特化 | 多くの競合はサンプル局面やプロの対局が中心 |
| **Web対話型** | ブラウザからすぐ使える | 銀星将棋10はパッケージソフト、将棋ウォーズはアプリ内限定 |
| **初心者特化** | ウォーズ5級〜3級に完全フォーカス | 多くのサービスは「全レベル対応」と謳うが、解説の実質的な難易度は中級者以上 |
| **評価値の言語化** | 数字を見せず「やや有利」等の言葉で表現 | ほとんどの既存サービスは数値をそのまま表示 |

## 7. リスクと機会

### リスク
- **銀星将棋10が2026年4月3日発売**: 本プロジェクトのMVP時期と重なる。商用品質の解説AIが市場に出る
- **水匠チームの一般公開**: 現在は研究段階だが、一般公開されると強力な競合になりうる

### 機会
- **対話型は未開拓**: 将棋解説AIで「追加質問に答える」機能を持つサービスはまだない
- **Web即アクセス**: パッケージソフトやアプリ内機能と異なり、URLだけで使えるのは差別化
- **初心者完全特化**: 既存サービスは「全レベル対応」が多く、初心者への深い最適化は少ない
